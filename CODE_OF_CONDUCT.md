# Code of conduct

We are committed to a harassment-free, inclusive collaboration environment.

Be respectful, assume good intent while addressing impact, give actionable
technical feedback, protect private information, and accept maintainers'
decisions about project scope. Harassment, discrimination, threats, doxxing,
sexualized conduct, and sustained disruption are not acceptable.

Report conduct concerns privately to the repository owner using the verified
contact method on their GitHub profile. Reports will be handled as confidentially
as practical. Maintainers may edit or remove contributions and temporarily or
permanently restrict participation when necessary to protect the community.

This policy applies in project spaces and when representing the project elsewhere.
